## Overview
This extension is an independent productivity tool designed to help students manage course pacing.
- **Zero data collection:** No personal data, tracking cookies, or browsing history are collected or transmitted.
- **Local storage only:** Interface preferences and optional user-provided AI keys are saved strictly in `chrome.storage.local`.
- **Direct API communication:** Host requests go directly to Coursera and official AI endpoints (Google Gemini, OpenAI, Groq) using client-side requests only.
